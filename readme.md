# Improved Hierarchical Analysis Method (Matlab Code Implementation)

Improved Analytic Hierarchy Process (Matlab Code Implementation)
The improved Analytic Hierarchy Process is a modification of the traditional Analytic Hierarchy Process. Its main characteristics include:
(1) Replacing the nine-point scale method with the three-point scale method to reduce the impact of subjectivity on evaluation results;
(2) Using the optimal transmission matrix to construct the judgment matrix, directly determining weights without the need for consistency testing.
